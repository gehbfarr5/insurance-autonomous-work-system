# 保险规划师自主工作系统
**Autonomous Insurance Work System**

> 让 AI 主动发现值得做的工作，在明确授权下组织执行、验证成果和持续改进；同时与保险规划师共同探索客户经营方法和专业成长，而不是仅把现有操作自动化。

## 两套阶段的区别

- **P0—P3：规划工作的决策关口。** P0 是总体框架整理；后续 P1 为真实业务需求地图，P2 为试点候选评估，P3 才是所选范围的具体方案。它们不是软件版本号。
- **S1—S3：候选自主能力发展路线。** S1 可靠执行与减负，S2 跨业务协同，S3 更深入的经营协作和进化。**只是候选结构，细节与阶段数均未最终确定。**
- 原 [Issue #1](https://github.com/gehbfarr5/insurance-autonomous-work-system/issues/1) 的旧标题中“Phase 2”只指业务需求讨论入口，**不要把它理解为系统能力阶段 S2 已开始**。

## 长期协作模式

- **你主导：** 重要客户关系、面对面交流、职场一手情境与重大经营判断。
- **AI 先提议：** 月度经营计划、跨业务机会与方向复评，双方共同判断。
- **AI 自主处理：** 既有授权范围内的日常任务、周度行动组织、具体事项的增减调整、验证与问题处理。
- **双向成长：** AI 不只是减轻工作，也应通过证据、复盘和讨论帮助你逐渐形成更独立的业务判断。

长期成效从**经营成果、人工减负、客户关系质量、个人专业成长**四个维度共同评价，不以任务数替代效果。

## 文档状态与维护约定

- **已确认**：经用户明确同意的方向；记录在决策日志。
- **候选/暂定**：用于比较的业务闭环或阶段方案，尚未获最终确认。
- **待研究**：所需业务事实、权责、数据或验证依据不足。
- **长期目标**：未来希望实现的自主能力，不代表系统已上线。
