# 保险规划师自主工作系统
**Autonomous Insurance Work System**

> 一个长期 AI 项目，目标是重新思考保险规划师的工作应如何完成：让 AI 在明确目标、权限与验收规则内主动发现工作、执行任务、验证结果并持续改进流程。

## 项目状态

**总体规划阶段。** 项目愿景、思想指导、自主性方向和设计原则已确认；业务需求、优先级、技术架构及开发方案仍待讨论。本仓库用于沉淀共识和管理规划文档，不包含已实现系统或业务代码。

## 核心方向

项目长期以 Felix Rieseberg 的文章 [How to be more ambitious: A tutorial for humans with models](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/) 为思想指导，并以 Speed、Altitude、Depth、Range 四个维度检视项目选择。详见[思想指导与设计原则](docs/01-philosophy-and-principles.md)。

项目追求高度自主执行与持续自主进化：人类负责目标、重要关系和关键判断；AI 在预先设定的目标、权限、验收及回滚规则内承担常规工作。以上是长期能力目标，不表示这些能力已经实现。
