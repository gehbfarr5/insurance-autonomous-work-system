- 常规外呼、信息发现、客户资料组织等后续候选：保留经营价值与依赖，尚未批准与首批同时实施。

## 3. 已关闭的问题，不重复询问

- C 为 S1 首个试点域，每日互动为首项切入；两块 APP 样本不是封闭范围。
- 助手按页面反馈行动、主动检查任务；新任务在规则内自主处理，边界不明交接。
- 不确定状态先核查、安全才重试；异常按紧急程度通知。
- Android 注入为必要前提；现有环境曾验证可用，技术记录保留；不代表新系统验证完成。
- 当前设备是 M5 Pro MacBook、iPhone 17、Pixel 3a；旧设备清单仅作历史。
- 优先云端化，以日常只用 iPhone 为目标；不满足再考虑 Pixel 独立执行。
- 用户确认公司允许适用、资料可交云端；不写成独立制度核查或无限制数据许可。
- 没有独立测试环境；本地模拟与有限真实验证分开。
- P3 按框架层面收尾；P4 为分批具体设计、实施与验证，不预设为最终阶段。
