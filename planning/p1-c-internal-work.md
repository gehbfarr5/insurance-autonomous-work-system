# P1-C｜内部事务与工作组织（调查中）

> 初稿：2026-10-24。根据已确认的总体范围建立访谈入口，不表示这些项目已逐一验证其频率、实际耗时或授权。公开 GitHub 不记录内部群消息原文、账号凭据、人员隐私或业务敏感信息。

## 1. 已确认的总体业务范围

- 公司与主管下达的要求、临时事项。
- 培训、学习和考试。
- 签到、报名、资料提交等行政操作。
- 公司会议、客户预约和个人工作日程。
- 公司活动的参与、客户参会组织及安排，与 P1-B 信息发现和 P1-A 客户经营存在交叉。
- 用户现有经验中，日常**时间冲突并非主要工作矛盾**，不能将日历冲突预设为最关键价值。

## 2. P1-C 最小事实调查

目前尚不清楚：
1. 哪几类事务实际最频繁、最耗时、最让人费精力，是否容易遗漏？
2. 哪些是要求必须参加或完成的，哪些是用户主动选择的？
3. 这些事务怎样知道已经真正完成？提交、回执、主管认可、现场签到等不应当混为一谈。
4. 哪些必须由用户本人执行或判断，哪些属于希望在未来委托 AI 的重复事务？

## 3. 阶段边界

- 此处调查的是**真实工作负担和主要业务结果**，不要求给出完整内部系统、考试或报名工作说明。
- AI 尽可能承担常规事务是用户总体愿景；但目前未做单项外部权限授权或实现选择。
- 待用户分享实际主要类别后，整理事实、待定和可供 P1-D 讨论的结果核验例子，不直接挑选 S1 试点。
