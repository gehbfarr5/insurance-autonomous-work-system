## 3. 初步排序建议（分析判断，非试点决定）

### C：已确认作为 S1 首个试点

用户于 2026-10-24 明确选择 C 作为 S1 首个试点，并补充确认 C 的业务范围包括每日互动任务、培训课程、题目答题相关的日常、特定活动、客户筛选内容报送、每月收入计划等公司要求完成的细碎工作。C 因此是一个内部日常工作域，覆盖操作型与内容型事务。

该选择确认了试点业务域，不表示所有任务必须在同一批次同时实施。建议在保留上述完整业务范围的前提下，依据任务频率、流程稳定性、结果证据和依赖关系分批细化；每日互动任务的完全代办已明确，其他类别的自主执行边界及校验方式留待评估。具体页面反馈和异常规则在未来实际操作中结合用户反馈迭代。

### A：价值最高的长期减负目标之一

A 对应用户明确指出的最大时间精力负担，并且直接联系客户经营。它应保持在候选前列，但自主外联比 C 带来更多对外影响和结果判断要求。可在后续比较是否先从准备与组织等边界较清楚的工作切入，之后再评估自主联系范围；此处不预设实施顺序或授权。

### B：可核验业务闭环的备选

B 有现存 Agent 报名经验与可检查结果，可作为 C 的替代 S1 候选。可比较明确活动通知到报名确认的有限闭环；全群消息筛选、客户匹配、代客户报名和日程协同不默认一次性纳入。

### D：潜在共享基础能力

D 可能为 A、B 提供客户资料和跟进组织能力，但资料权限、现有记录方式和减负规模尚不清楚。当前将它列为候选基础能力，不预设独立成为 S1 或先于其他场景实施。
